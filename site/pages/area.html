An area chart is a line chart with the space under each line filled in.

{{example area}}

When to use it

Use an area chart when the size of the values matters as well as their trend, or stack it to show how parts add up to a total over time.

Options

OptionOn an area chart
type: areaRequired.
titleText above the chart.
x-labelTitle for the label axis.
y-labelTitle for the value axis.
stackedtrue stacks the areas. Each one fills down to the series below it.
legendtop, bottom or none.
heightChart height in pixels, 120 to 1200.
colorsOne colour per series. The fill is a see-through version of the line colour.
paletteA palette from settings.
source, x, yDraw from note properties.

The value axis starts at zero, because the filled area stands for the amount.
