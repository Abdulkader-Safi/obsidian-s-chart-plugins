The quickest way in is the Insert chart command. It puts a working sample block at the cursor, which you then edit.

Insert a sample

  1. Open a note and place the cursor on an empty line.
  2. Open the command palette (Ctrl or Cmd + P) and run S-Charts: Insert chart.
  3. Move the cursor out of the block. The chart draws.

The command has no hotkey by default. You can add one in Settings → Hotkeys.

Parts of a block

{{code intro}}
  • ```s-chart opens the block. The language must be s-chart.
  • Each line above --- is an option, written key: value. Only type is required. All options are in the options reference.
  • The --- line separates options from data.
  • The table is the data. The first column holds the labels and every other column is one series. See Writing the table.

Change the chart

Change type: bar to type: line and move the cursor out of the block: the same table now draws as a line chart. Every chart type reads the same table, so you can try each one without retyping anything.

Edit a chart later

In live preview, hover over a chart and select the </> button in its top-right corner. The block opens as text. You can also move into it with the arrow keys.

Reading view shows the chart but has no edit button. Switch to live preview or source mode to edit.
