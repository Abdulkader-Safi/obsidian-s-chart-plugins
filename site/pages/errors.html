Errors

An error stops the chart from drawing until you fix it.

MessageFix
missing type. Add a line like type: bar.Add a type line above ---.
unknown type "bars". Use bar, line, area, pie, doughnut, scatter or radar.Use one of the listed types.
no "---" line. Put --- between the settings and the table.Add a line with just --- above the table.
no table after "---". Add a markdown table.Add the table, or use source for properties.
the table has no number columns. Add a column after the labels.The table needs at least two columns.
the table has a header but no rows.Add at least one row under the header.
can't read "lots" as a number in column "Revenue".Use a number or leave the cell empty. See number formats.
not a table row: "...". Rows start with |.Remove the stray line or start it with |.
can't read "...". Use key: value.Options above --- must be key: value.
scatter needs a number in the first column, not "...".Scatter's first column is an axis. See Scatter.
source needs an x: line / a y: line.Add the missing line. See Charts from properties.
No notes match "#daily".Check the tag or folder path.
12 notes match "#daily", but none has the property "date".Check the spelling of x.

If the plugin itself fails

"S-Charts hit a bug, please report it." means the plugin broke, not your block. Please open an issue with the block's text.
