Plugin settings

Open Settings → S-Charts. Every change saves at once and redraws open charts.

Default palette

Theme uses your theme's colours. Pick one of your palettes to use it on every chart that has no palette or colors line.

Default height

Chart height in pixels for charts without a height line. 120 to 1200, 300 to start. A value outside that range is marked and not saved.

Animations

Charts animate when they first draw. Turn this off to draw them at once. Animation is always off in PDF export.

Palettes

Add, rename, recolour, reorder and delete palettes. Each palette row has a name field, then one row per colour with a colour picker, a hex field, arrows to move it earlier or later, and a button to remove it. See Colours and palettes.

  • A name that is already taken, or uses characters other than letters, numbers, - and _, is marked and not saved.
  • A colour that isn't a hex code or a var(--name) is marked and not saved.
  • Deleting a palette asks first.

Where settings are stored

In .obsidian/plugins/s-charts/data.json inside your vault, so they sync with the vault.
