Options go above the --- line, one per line, written key: value. Only type is required. Keys are lower case, and values can be wrapped in quotes.

Which options work on which type

Options that don't apply to a type are ignored without a warning, so you can switch type freely. A heatmap uses only the first colour from colors or palette.

Misspelt options
